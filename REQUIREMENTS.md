# Requirements

| ID        | Final / Updated Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| :-------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FR1**   | The system shall follow the 18 mm black line on its own, using two IR sensors that straddle the line (left analog on ADC0, right digital on GP17). Nobody steers the car during a run.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **FR2**   | The system shall treat 150 mm of travel with both line sensors on white as line lost. It shall then search: pivot 20° towards the side last seen, 40° the other way and back to the centre, creep 50 mm, and repeat until the car has moved 300 mm. If the line is still missing, it raises `LINE_SEARCH_FAIL` and enters Fault.                                                                                                                                                                                                                                                                                 |
| **FR3**   | The system shall detect a cross junction when both line sensors read black for at least 10 ms and 8 mm of travel. It reports each crossing once and re-arms only after 40 mm.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **FR4**   | The system shall decode Code 39 barcodes A–Z read in either direction. Bar widths are measured as the distance the barcode sensor travels (from both wheel encoders, 0.1 mm steps), so the reading holds when speed changes. Misreads are logged and counted, and the car keeps following the line.                                                                                                                                                                                                                                                                                                              |
| **FR5**   | The system shall hold the last decoded letter until the next junction. A new barcode replaces the held letter. At the junction it drives 130 mm so the axle sits over the cross, then performs the mapped move: forward, left 90°, right 90° or U-turn 180°. A junction with no letter held uses the default move.                                                                                                                                                                                                                                                                                               |
| **FR6**   | The system shall take a new letter-to-move mapping over MQTT at any time, without recompiling. The whole payload is checked first, and payloads over 127 bytes are refused. A bad payload changes nothing and gets an “error” reply on `map/ack`. A good one replaces the table in one step between Supervisor events and gets an “ok” reply. Until a mapping arrives: A = forward, B = left, C = right, D = U-turn.                                                                                                                                                                                             |
| **FR7**   | The system shall control each wheel's speed in a closed loop (PI on encoder feedback) so the car drives straight despite motor differences. It supports four speed levels: stop, slow, hump (50 % of cruise) and cruise.                                                                                                                                                                                                                                                                                                                                                                                         |
| **FR8**   | The system shall pivot to commanded angles (2° steps) using encoder counts. After a junction pivot it checks the result against the compass and makes one correction if the error is over 5° and at most 30°.                                                                                                                                                                                                                                                                                                                                                                                                    |
| **FR9**   | The system shall detect a hump under the right wheel from IMU tilt (raised more than 5.5 mm for 4 samples and 10 mm of travel). It then slows to hump speed while it keeps following the line, and returns to cruise after 100 ms back at level.                                                                                                                                                                                                                                                                                                                                                                 |
| **FR10**  | The system shall estimate each hump's height while moving, count the humps, and record the highest peak. The height is 0–31 mm in 1 mm steps.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **FR11**  | The system shall check for obstacles while running. In Line Follow, when 2 of 3 readings are under 40 cm, it stops once and sweeps the servo ±35° to find both edges and the width, then drives on. In Line Follow and Hump it stops for the bypass when 2 of 3 readings are under 21 cm, about 15 cm from the car's front. One reading under 6 cm stops it at once; that is the only check during junction moves and the bypass side-steps and approach. While passing the box it watches only the box's side, and during bypass pivots it does not check. Line Search keeps the checks of the state before it. |
| **FR12**  | The system shall go around the obstacle on the side with more room, chosen from the width sweep (left if unclear). It uses a 50° side-step with a side scan after each step, passes the box, turns back and drives onto the line. If no side fits, or the bypass takes over 60 s, it raises `NO_BYPASS` and enters Fault.                                                                                                                                                                                                                                                                                        |
| **FR13**  | The system shall publish a 14-byte binary status frame with CRC-8 every 500 ms. The frame holds state, faults, odometer, speed, heading, terrain, speed level, roll, pitch, hump count and last letter. It also publishes one JSON event per state change, barcode, junction, command, obstacle width and hump, each with its x/y position, to build a rough course map.                                                                                                                                                                                                                                         |
| **FR14**  | The system shall answer a snapshot request from the PC with a JSON summary of the current state. The summary holds state, faults, odometer, speed, x/y, heading, tilt, humps, barcodes, pending letter, obstacle width, bypass side and mapping. Telemetry and commands keep flowing while it answers.                                                                                                                                                                                                                                                                                                           |
| **FR15**  | The system shall start and stop a run from the START button or the PC panel. Holding MODE 2 s in Idle enters Calibrate (IR thresholds, IMU level and compass). A short MODE press clears a Fault. The RGB LED shows a colour per state, and the buzzer beeps on events and faults. Finished is entered by the end-of-course trigger, which will be set once the course is released.                                                                                                                                                                                                                              |
| **FR16**  | The system shall stop the motors and enter Fault on: motor stall (both wheels driven at 30 % or more with no counts for 300 ms), encoder fault (one wheel the same), IMU read failure (3 in a row), impact (over 2 g for 2 samples, ignored for 300 ms after a hump), ultrasonic fault (10 pings with no echo start), failed line search, no bypass, the car lifted while running, or a failed start-up. Losing Wi-Fi is not a fault.                                                                                                                                                                            |
| **NFR1**  | The software shall be written in C with the Pico SDK and run on µT-Kernel 3.0 using both RP2040 cores. The code in `app_program/` shall follow the Barr-C:2018 layout rules, and the software shall build from the course template repository.                                                                                                                                                                                                                                                                                                                                                                   |
| **NFR2**  | Task periods shall be: Motion Control 10 ms, Line Following 5 ms, Barcode 1 ms, IMU 20 ms, Obstacle Scan 50 ms while it pings, Telemetry 500 ms, on a 1 ms kernel tick. Each task has a fixed, unique priority (8 to 15). Motion Control and Line Following period jitter shall stay at or under 500 µs.                                                                                                                                                                                                                                                                                                         |
| **NFR3**  | Motion Control shall read the fault flag every 10 ms cycle and cut the motors in the same cycle that any stop bit is set.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **NFR4**  | A commanded 90° turn shall finish within ±5° of the target.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **NFR5**  | The car shall come to rest 14–16 cm from an obstacle's face (at least 10 cm clear) in 10 of 10 runs. Obstacle width shall be within ±15 mm for boxes 50–100 mm wide.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **NFR6**  | Peak hump height shall be within ±5 mm of the true height in 8 of 10 runs over a hump of known height.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **NFR7**  | Telemetry shall be published every 500 ms (twice per second on average), and a snapshot request shall be answered within 500 ms.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **NFR8**  | Losing Wi-Fi shall not affect driving. Wi-Fi and MQTT run on core 0 in the kernel's Wi-Fi task (priority 4), the fast control loops run on core 1, and MQTT reconnects on its own.                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **NFR9**  | Each device shall have one owner task; the safety watch may still switch the motors and buzzer off. Subsystems shall talk only through the interfaces in `TEAM.md` section 5 and the telemetry hand-over to the Wi-Fi task; telemetry may also read other subsystems' status counters. Message formats, the decoder, the mapping parser and the telemetry frame shall pass the host unit tests without hardware.                                                                                                                                                                                                 |
| **NFR10** | Each application data field shall use only the bits its valid range needs, packed with explicit shifts and masks. Examples: state 4 b, letter 5 b, junction 2 b, hump height 5 b, heading 9 b. Raw hardware data and timers keep their native width.                                                                                                                                                                                                                                                                                                                                                             |
| **NFR11** | Junction, barcode and fault events shall never be dropped. `mbf_sup_event` holds 16 messages and keeps 6 slots free. Only line samples and snapshot requests may be dropped when it is nearly full, and each drop is counted.                                                                                                                                                                                                                                                                                                                                                                                    |
